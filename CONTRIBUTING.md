# Contributing to Ninja Paws Repositories

Thank you for considering a contribution. Ninja Paws repositories are community
and demo projects, and contributions from both the public and Microsoft
employees are welcome where the target repository accepts them.

Before contributing, read the repository's local `CONTRIBUTING.md`, `README.md`,
`SECURITY.md`, and `DISCLAIMER.md`. Local repository guidance takes precedence
over this organization default.

## Contribution Expectations

- Keep changes focused and explain why they are needed.
- Include validation steps and results in pull requests.
- Do not commit secrets, credentials, tokens, tenant exports, customer data,
  production logs, or other sensitive information.
- Prefer sample data over real tenant or customer data.
- Verify Microsoft product, licensing, pricing, and security statements against
  official Microsoft documentation before adding them.
- Preserve independent-project notices and trademark clarity.

## Microsoft Employee Contributions

Some contributors may be Microsoft employees. Unless a repository explicitly
states otherwise, employee contributions are made in an individual or community
capacity and do not imply Microsoft approval, endorsement, sponsorship, support,
roadmap commitment, legal advice, licensing advice, or professional services
deliverables.

## Pull Request Checklist

Include the following when relevant:

- Summary of what changed and why.
- Tests, build commands, linting, or manual validation performed.
- Any security, privacy, tenant-data, cost, licensing, or deployment impact.
- Links to official Microsoft or GitHub documentation for product behavior.
- Screenshots or sample output for user-facing changes.

## Security Issues

Do not report vulnerabilities in public issues. Use the repository's Security
tab or the private process described in `SECURITY.md`.

By contributing to a repository, you agree that your contribution is provided
under that repository's license unless the repository says otherwise.
