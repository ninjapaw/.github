# Ninja Paws

![Ninja Paws mark](./ninjapaws-mark.svg)

Ninja Paws is an independent community and demo organization for practical
examples around Microsoft security, management, productivity, compliance, cloud,
and AI technologies.

The repositories here are built for learning, demonstrations, reference
architectures, estimators, and repeatable scenario work. They are public so the
community can inspect, reuse, challenge, and improve them.

## Contributing

Contributions and suggestions are welcome. Please read each repository's local
`CONTRIBUTING.md` first. If a repository does not define one, use the default
organization guidance in this repository.

Report bugs, documentation issues, and feature requests in the repository where
the issue applies. Do not include secrets, tenant data, customer data, tokens, or
other sensitive information in public issues or pull requests.

For security vulnerabilities, use the repository's Security tab or follow the
private reporting process described in its `SECURITY.md`.
