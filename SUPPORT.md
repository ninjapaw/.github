# Support

Ninja Paws repositories are community and demo projects. They do not include
Microsoft support, GitHub support, production support, service-level agreements,
or professional services obligations.

## Is This an Official Microsoft Product?

No. Ninja Paws repositories are independent community and demo projects. They may
be maintained or contributed to by Microsoft employees, but that participation is
individual or community activity unless a repository explicitly says otherwise.
Do not contact Microsoft Support or GitHub Support for Ninja Paws project issues.

## Where to Ask

- Use the target repository's issues for bugs, documentation problems, feature
  requests, and reproducible demo problems.
- Use pull requests for proposed fixes or improvements.
- Use official Microsoft support channels, Microsoft Learn, Microsoft Product
  Terms, Azure pricing pages, and your Microsoft account team for product,
  licensing, purchasing, compliance, tenant, subscription, or production support
  questions.

## Security

Do not open public issues for vulnerabilities or sensitive data exposure. Use the
repository's Security tab or follow its `SECURITY.md`.

## Public Issue Hygiene

Do not post secrets, credentials, access tokens, tenant IDs unless they are
public test tenants, customer data, private logs, screenshots containing
sensitive information, or proprietary environment details.
