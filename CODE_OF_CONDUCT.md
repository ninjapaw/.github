# Code of Conduct

Ninja Paws follows the [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/)
as the baseline behavior standard for these community repositories. This does
not make Ninja Paws a Microsoft project, product, or support channel.

Resources:

- [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/)
- [Microsoft Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/)

Ninja Paws repositories are public community spaces for practical learning and
collaboration.

## Expected Behavior

- Be respectful, constructive, and specific.
- Assume good intent while still asking for evidence and validation.
- Keep discussion focused on the repository, issue, pull request, or demo.
- Respect privacy and confidentiality. Do not share tenant data, customer data,
  secrets, credentials, or private communications.
- Accept maintainers' decisions about scope, safety, and project direction.

## Unacceptable Behavior

- Harassment, threats, hate speech, personal attacks, or discriminatory language.
- Publishing private information without permission.
- Sharing malware, exploit instructions, credentials, or tenant/customer data in
  public project spaces.
- Misrepresenting Ninja Paws as an official Microsoft or GitHub product,
  service, endorsement, or support channel.

## Reporting

Report conduct concerns in the repository where they occur, using private
channels when sensitive information is involved. Security vulnerabilities should
be reported through the repository's Security tab or `SECURITY.md` process, not
through public issues.
