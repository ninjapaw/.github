# Governance

Ninja Paws is an independent community and demo organization. Repository
maintainers guide scope, review changes, and decide what is accepted into each
project.

## Maintainer Responsibilities

- Keep repositories safe for public consumption.
- Preserve clear disclaimers, license references, and trademark notices.
- Prefer official Microsoft and GitHub documentation for product behavior.
- Review security, privacy, tenant-data, deployment, licensing, and cost impact
  before merging changes.
- Keep demo and sample code reproducible, bounded, and clearly documented.

## Contributor Responsibilities

- Follow the target repository's local contribution guidance.
- Provide tests, validation, or evidence for changes where practical.
- Avoid committing secrets, tenant exports, customer data, or proprietary data.
- Make clear when a statement is a recommendation, estimate, or assumption.

## Microsoft and GitHub Notice

Ninja Paws repositories are not Microsoft or GitHub products unless explicitly
stated in the repository. Contributions from Microsoft employees or GitHub users
do not imply Microsoft or GitHub approval, endorsement, sponsorship, or support.

## Changes to Governance

Governance changes should be made by pull request and reviewed like any other
public-facing project change.
